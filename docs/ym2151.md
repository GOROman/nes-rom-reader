# YM2151 FM音源カートリッジ (実機検証済み)

ダンパーのカートリッジスロットに「YM2151 を載せたポパイ(HVC-PP)改造カートリッジ」を
挿して、実チップの FM 音源を鳴らす。X68000 の MDX 曲データの再生に対応。

- ファーム: `feature/ym2151` ブランチ (famidump v0.6)
- リーダー基板は **v0.1 のまま完全無改造**(U6 DIR 改造・BUS_DIR 不要)
- φM = **4MHz**(X68000 ネイティブ。ピッチ補正不要)

## 駆動方式: フルアドレスバス書き込み

YM2151 への制御はすべて **CPU アドレス線**(74HCT595 が常時 5V 駆動)で行う。
データバス(U6)を使わないため基板改造が不要。

| 役割 | アドレス線 | 補足 |
|---|---|---|
| D0-D7 | CPU A0-A7 | データ/レジスタ番号 |
| A0 | CPU A8 | レジスタ/データ選択 |
| /WR | CPU A9 | srWrite32 3回でストローブ生成(幅数十µs、YMはスタティックなので可) |
| /IC | CPU A10 | 起動直後はSRが全0=リセット状態で待機(好都合) |

BUSY は読めないため 30µs 固定ウェイト。/CS=GND・/RD=+5V 固定。

## ポパイカート側 配線表 (検証済み)

**PRG ROM (28ピン JEDEC, /CE=/ROMSEL は切断済み) の足:**

| YM2151 ピン | 信号 | PRG ROM の足 |
|---|---|---|
| 10,12,13,14,15,16,17,18 | D0-D7 | pin 10,9,8,7,6,5,4,3 (A0-A7) |
| 4 | A0 | pin 25 (A8) |
| 5 | /WR | pin 24 (A9) |
| 3 | /IC | pin 21 (A10) |
| 6 | /RD | pin 28 (+5V 固定) |
| 7 | /CS | pin 14 (GND 固定) |
| 22 | VDD | pin 28 (+5V) + パスコン 0.1µF |
| 1, 11 | VSS | pin 14 (GND) **2本とも** |
| 2, 8, 9 | /IRQ, CT1, CT2 | 未接続 |

**CHR ROM (28ピン) の足 — 音声シリアル出力(割り当て固定):**

| YM2151 ピン | 信号 | CHR ROM の足 | 経路 |
|---|---|---|---|
| 23 | φ1 | pin 11 (D0) | → エッジ26 → U7 → G4 (MD0) |
| 21 | SO | pin 12 (D1) | → エッジ27 → U7 → G5 (MD1) |
| 20 | SH1 (R) | pin 13 (D2) | → エッジ28 → U7 → G6 (MD2) |
| 19 | SH2 (L) | **pin 16 (D4)** | → エッジ60 → U7 → G8 (MD4) |

※ SO は1本に L/R が時分割で乗り、SH1/SH2 が各chワードの区切りを示す。
※ pin 14 は GND、pin 15 は本機ではパッド不調のため pin 16 を使用。
※ 割り当てはファームに固定(自動判別は誤判定するため廃止)。
※ **CHR ROM pin 22 (/OE) は足上げし、浮いた足を +5V へ接続**(ROM恒久無効化。
   フローティングだとROMがバスに出てきて全信号が潰れる)。

**エッジフィンガー直付け(1点のみ):**

| YM2151 ピン | 信号 | 位置 |
|---|---|---|
| 24 | φM | エッジフィンガー 32 (M2)。NROMでは未使用なのでパターンなし=フィンガーに直接ハンダ |

## YM3012 シミュレーション (ファーム内蔵・ステレオ)

実 YM3012 を使わず、Core 0 の専用タスクが SO/SH1/SH2/φ1 を Dedicated GPIO
(1サイクル読み)で取り込み、13bit浮動小数点(10bit仮数+3bit指数)を L/R 独立に
デコードして **78.125kHz/9bit PWM ×2ch** を出力する(fs=φM/64=62.5kHz)。
フル精度デコード+1次ノイズシェーピング(アンチワインドアップ付き)。

- ハーフフレーム(16φ1)ごとにエッジ数を検証(13-17。先頭3ビットは捨てビット
  なので処理遅延ぶんの取りこぼしを許容)。化けたフレームは破棄して直前値保持
- SH2 未配線時はモノラル(SH1→Rのみ、窓29-33)で後方互換動作

**音声PWM出力(カートリッジ側へ出す。リーダー基板は無改造):**

| ch | ESP32 | 経路 | タップ位置 |
|---|---|---|---|
| R | G2 (PPU /RD) | 541 → エッジ17 | CHR ROM pin 22 の基板側パッド |
| L | G41 (/ROMSEL) | 541 → エッジ44 | エッジフィンガー44 (または PRG pin20 カットのエッジ側) |

各タップ → 2.4kΩ → (4.7nF→GND) → 1µF(DCカット) → アンプ L/R

## コマンド (famidump v0.6)

```
F              -> YM初期化: φM 4MHz供給 + /ICリセット。"YMRDY"
Y <reg> <val>  -> レジスタ書き込み (hex)
Q              -> ドレミファソラシドをループ再生(次のコマンドで停止)
E              -> 内蔵曲「Flash Flash Flash」(ボスコニアン、約135秒)を再生
X              -> MDXイベントストリーム再生 (host/mdx/mdxplay.py から)
A              -> テストトーン: R=880Hz / L=440Hz を3秒(左右配線チェック用)
D              -> 信号診断(全信号エッジ数、L/R採用率とduty範囲、median/badExp統計)
O <L> <R>      -> デコードビットオフセット調整(実験用、既定0、範囲-2..+3)
G              -> Rラッチ時の生ワード64個を記録してダンプ(アライメント解析用)
N <0|1>        -> メディアンフィルタの無効/有効(既定1)
```

**スタンドアロン動作**: 電源ONから2秒以内にシリアル入力がなければ、
内蔵曲を自動でループ再生する(曲間3秒)。USB充電器だけで動く。
φM は 4MHz(X68000ネイティブ、ピッチ補正なし)。内蔵曲の差し替えは
.evt から firmware/src/embedded_song.h を再生成する。

## MDX 再生パイプライン (host/mdx/)

```
*.MDX ──(mdxdump: portable_mdxのMXDRVでOPMレジスタ書き込みを
          タイムスタンプ付きで抽出)──→ *.evt
*.evt ──(mdxplay.py: 4バイトレコード化+フロー制御ストリーミング)──→ X コマンド
```

- `host/mdx/build.sh` で mdxdump をビルド(third_party/portable_mdx 使用。
  sound_iocs.cpp に書き込みフックを追加してある)
- ADPCM(PDX)チャンネルは YM2151 単体では鳴らない(FM 8ch のみ)
- φM を 4MHz 以外で駆動する場合は `mdxplay.py --tune <実測Hz>` で
  KC/KF ピッチ補正(1/64半音単位)が掛かる

## 既知の問題と対策済み事項

- **電源リセット(rst=9 Brownout / rst=1)**: アンプの消費電流で5Vがサグして発生
  していた。バルクコンデンサ追加で解消(再発時はアンプ電源の別系統化を)
- フレーム採用率は L/R とも約99%(検証窓13-17、Dedicated GPIO 1サイクル読み)
- VGM 再生は host/mdx/vgm2evt.py で変換(vgmrips のパック等)。ADPCM/OKIM6258
  パートは鳴らない(YM2151 の FM 8ch のみ)
