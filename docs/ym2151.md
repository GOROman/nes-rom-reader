# YM2151 を基板上で鳴らす (実験機能)

ダンパーのカートリッジスロットに「YM2151 を載せた改造カートリッジ」を挿して
YAMAHA YM2151 (OPM) を駆動する。ファーム `feature/ym2151` ブランチ (famidump v0.6) の
`F` / `Y` / `Q` コマンドで制御する。

## 方式: アドレスバス書き込み

YM2151 の制御をすべて **CPU アドレス線**で行う: D0-7 = A0-A7、A0 = A8、
/WR = A9、/IC = A10。アドレス線は 74HCT595 (U2/U3) が常時 5V で駆動しているため、

- リーダー基板は **完全無改造・全リビジョンで動作** (U6 DIR 改造や BUS_DIR 不要)
- 信号レベルも 5V フルスイングでマージン問題なし
- カート側のハンダ付けは **PRG ROM の足 + エッジフィンガー32 (φM) の1点だけ**
- /WR パルスはシフトレジスタ更新で作る (幅数十µs。YM2151 はスタティック入力
  なので上限なし、min 100ns を満たせば良い)
- 起動直後〜`F` 実行前はシフトレジスタが全0 = /IC=Low なので YM はリセット状態に保たれる

BUSY フラグは読めないので、書き込み間隔は固定ウェイト
(BUSY 最大 68 φM サイクル ≒ 19µs → 30µs 待ち) で代替する。

## 改造カートリッジ (実績: ファミコン「ポパイ」HVC-PP)

NROM カートの PRG ROM /CE (=/ROMSEL) と CHR ROM のセレクト線をカットして
両 ROM を無効化し、基板を 60 ピンエッジのキャリアとして使う。

## 配線

| YM2151 ピン | 信号 | 接続先 | 備考 |
|---|---|---|---|
| 10, 12–18 | D0–D7 | **PRG ROM pin 10→3** (CPU A0–A7、連続8本) | エッジ13〜6 相当 |
| 4 | A0 | **PRG ROM pin 25** (CPU A8) | レジスタ/データ選択 |
| 5 | /WR | **PRG ROM pin 24** (CPU A9) | srWrite32 でストローブ生成 |
| 3 | /IC | **PRG ROM pin 21** (CPU A10) | リセット。F コマンドでパルス |
| 6 | /RD | **+5V に固定** (PRG ROM pin 28) | ステータスは読まない |
| 7 | /CS | **GND に固定** (PRG ROM pin 14) | このカートは YM 専用 |
| 24 | φM | **エッジフィンガー 32** (M2) | ファームが LEDC PWM で 3.579545MHz を出力。フィンガー唯一のハンダ点 |
| 22 | VDD | PRG ROM pin 28 (+5V) | パスコン 0.1µF を YM 直近に |
| 1, 11 | VSS | PRG ROM pin 14 (GND) | **GND は 2 本とも接続** |
| 2 | /IRQ | 未接続 | オープンドレイン |
| 8, 9 | CT1, CT2 | 未接続 | |
| 21, 20, 19 | SO, SH1, SH2 | YM3012 へ | 音声シリアル出力 |
| 23 | φ1 | YM3012 の CLOCK へ | |

音声出力は YM2151 単体ではデジタル (SO/SH1/SH2/φ1) なので、アナログで聴くには
**YM3012 (DAC) + LPF + アンプ**を接続する。モノラルで良ければ SH1 側 (RIGHT) のみでも可。

## コマンド

```
F              -> φM供給開始 + /IC リセット。 "YMRDY"
Y <reg> <val>  -> レジスタ書き込み (hex)。   "YMOK 28 4A"
Q              -> デモ (A4-C#5-E5-A5 アルペジオ)。 "YMDEMO DONE"
```

例:

```
F
Q
```

## 注意

- `F` 実行後は M2 ピンが 3.58MHz クロック出力になるため、
  カートリッジ用コマンド (R/C/W/P/B) と併用しない。戻すには電源再投入。
- /CS=GND のため R/W をパルスする `P` / `B` コマンドを YM カートで実行すると
  ゴミ書き込みになる (YM 専用カートなので実害はないが混用しないこと)。
