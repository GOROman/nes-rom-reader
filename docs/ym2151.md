# YM2151 を基板上で鳴らす (実験機能)

ダンパーのカートリッジバスを流用して YAMAHA YM2151 (OPM) を駆動する。
ファーム `feature/ym2151` ブランチ (famidump v0.6) の `F` / `Y` / `Q` コマンドで制御する。

## 前提

- **データバスを駆動できる基板であること**: 基板 v0.2、または v0.1 の
  「U6 Pin.1 (DIR) を GND から切り離して G40 へジャンパ」改造済み基板。
  `platformio.ini` で `-DBOARD_REV=2` にしてビルドする。
- YM2151 使用中はカートリッジを挿さないこと(制御線を共有するため)。

## 配線

| YM2151 ピン | 接続先 | 備考 |
|---|---|---|
| D0–D7 | CD0–CD7 (U6 の B側 = カートリッジ CPU データバス) | 書き込みは3.3V駆動だが YM2151 入力は TTL 互換 (VIH=2.0V) なのでOK |
| /CS | /ROMSEL (カートピン) | 74HCT541 経由 5V |
| /WR | CPU R/W | 同上 |
| /RD | PPU /RD | ステータス(BUSY)読みに使用 |
| /IC | PPU /WR | リセット。F コマンドでパルス |
| A0 | CPU A0 (CA0) | シフトレジスタ U2.QA |
| φM (CLK) | M2 (カートピン) | ファームが LEDC PWM で 3.579545MHz を出力 |
| VDD | +5V | パスコン 0.1µF 必須 |
| VSS | GND | |

音声出力は YM2151 単体ではデジタル (SH1/SH2/SO) なので、アナログで聴くには
**YM3012 (DAC) + LPF + アンプ**を別途接続する。φ1 は YM2151 の CLKOUT(φ1) を使う。

## コマンド

```
F              -> φM供給開始 + /IC リセット。 "YMRDY st=00"
Y <reg> <val>  -> レジスタ書き込み (hex)。   "YMOK 28 4A"
Q              -> デモ (A4-C#5-E5-A5 アルペジオ)。 "YMDEMO DONE"
```

例 (440Hz を鳴らす最小手順は `Q` のデモ実装 `ymDemo()` を参照):

```
F
Q
```

## 注意

- `F` 実行後は M2 ピンが 3.58MHz クロック出力になるため、
  カートリッジ用コマンド (R/C/W/P/B) と併用しない。戻すには電源再投入。
- YM2151 への書き込みは BUSY (ステータス bit7) 解除待ちを挟んでいる。
